# Local APK Builder

A fully local, APK-only app builder that runs entirely on-device.

## Requirements

- Go 1.21 or later
- Git
- curl (for initial setup)

## Setup (Termux)

Clone repository:
  git clone <repository-url>
  cd local-apk-builder

Download dependencies:
  go mod download

## Run

Run server:
  go run ./cmd/app

Or using make:
  make dev

The server will start at: http://127.0.0.1:8080

## Test

Run tests:
  go test ./...

Run vet:
  go vet ./...

Build:
  go build ./cmd/app

## Verify

Check server is running:
  curl http://127.0.0.1:8080/

Check API:
  curl http://127.0.0.1:8080/api/project-state

## Architecture

Go application
  -> HTTP server (127.0.0.1)
  -> HTMX + Alpine.js UI
  -> SQLite
  -> Android WebView

## Runtime Types

The builder supports three runtime architectures. Choose per project on Screen 6 of the wizard.

| Type | Server | SQLite | APK Size | Coverage |
|---|---|---|---|---|
| `none` | No | No | ~3 MB | All devices |
| `go-sqlite` | Yes (localhost HTTP) | Yes | ~27 MB | All devices |
| `go-native` | No (JNI bridge) | Yes | ~15 MB multi-ABI / ~9 MB arm64 | arm64 + armv7 |

### go-native architecture

The `go-native` runtime uses the Candidate C pattern - no localhost, no HTTP server, no ports:

```
WebView (Capacitor)
  -> JS bridge (window.AppBridge)
  -> Kotlin plugin (AppBridgePlugin, @CapacitorPlugin)
  -> JNI (classes generated by `gomobile bind`)
  -> Go .so (libgojni.so - capgotest.AppCore)
  -> SQLite (modernc.org/sqlite)
```

Generated per project:

- `go-core/go.mod` - declares `golang.org/x/mobile/cmd/gobind` tool and `modernc.org/sqlite`.
- `go-core/core.go` - `AppCore` struct exposing `Health`, `SaveNote`, `GetNotes`.
- `build-go.sh` - runs `gomobile bind` for `android/arm64,android/arm`.

Guarantees locked by tests:

- `internal/generator/native_generator_test.go` - verifies Java plugin registration, method surface (`health`, `saveNote`, `getNotes`), JS bridge exposure on `window.AppBridge`, and the no-localhost invariant.
- `internal/build/native_runtime_package_test.go` - verifies `NativeRuntimeSourcesForRepo()` returns exactly 3 files, `go.mod` carries the `gobind` tool and `modernc.org/sqlite`, `build-go.sh` targets multi-ABI, and `core.go` exposes the expected methods.
## Database

SQLite database stored at: ~/.local-apk-builder/builder.db

## Security

- Server binds to 127.0.0.1 only
- Input validation on all user inputs
- Parameterized SQL queries
- No external dependencies
